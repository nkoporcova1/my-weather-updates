# My Weather — updates

This repo only distributes builds of the My Weather iPhone app through
SideStore. The app's source code lives elsewhere.

To get updates, add this source in SideStore (**Sources → +**):

```
https://raw.githubusercontent.com/nkoporcova1/my-weather-updates/main/apps.json
```

New versions then show up under **Updates**. They're published by
`weather-app/release.sh` in the app's repo.
